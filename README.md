# River Lounge Stay Website

Premium, fast-loading, fully responsive static website for **River Lounge Stay** (Sakleshpur, Karnataka).

## Tech
- HTML (`index.html`)
- CSS (`styles.css`)
- JavaScript (`script.js`)

## Included sections
1. Hero with background image + overlay
2. About
3. Rooms (Couple, 3 Sharing, 4 Sharing, 6 Sharing)
4. Gallery
5. Experience
6. Location (Google Maps embed)
7. Contact + WhatsApp booking

## Photo assets folder
Put your property photos inside `assets/` with these names:
- `bedroom.jpg` → Hero background / rooms mood
- `balcony.jpg` → Experience card
- `bathroom.jpg` → Gallery image
- `pool.jpg`, `pooltop.jpg`, `mural.jpg`, `nightview.jpg` → additional real gallery/experience visuals

## GoDaddy Deployment (riverloungestay.com)
1. Log in to GoDaddy hosting panel.
2. Open `public_html` using File Manager or FTP.
3. Upload these files/folders: `index.html`, `styles.css`, `script.js`, and `assets/`.
4. Ensure domain DNS/hosting mapping points to this account.
5. Open `https://riverloungestay.com` and hard refresh.
