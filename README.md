# River Lounge Stay Website

Modern single-page luxury homestay website for **River Lounge Stay**.

## Included
- Responsive landing page (`index.html`)
- Hero, About, Rooms, Experience, Gallery, Location, and Contact/Booking sections
- WhatsApp booking CTAs wired to: `https://wa.me/919740011515`
- Google Maps embed for Sakleshpur, Karnataka

## GoDaddy Hosting (riverloungestay.com)
1. Log in to GoDaddy and open your hosting panel.
2. Open **File Manager** (or connect via FTP).
3. Upload `index.html` to the `public_html` folder.
4. If replacing an existing site, back up/remove the old `index.html` first.
5. Confirm your domain `riverloungestay.com` points to this hosting account.
6. Visit `https://riverloungestay.com` and hard-refresh the page.
